# Expense Tracker

A simple command-line Expense Tracker built using Python. This project helps users manage daily expenses, organize spending by category, and generate basic expense reports.

## Features

- Add new expenses
- View total, average, highest and lowest expenses
- Generate category-wise expense reports
- Search expenses by item name
- Edit existing expenses
- Delete expenses
- Automatically save and load expense records

## Technologies Used

- Python
- CSV module
- File Handling

## How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Run the Python file:

   ```bash
   python expense_tracker.py
   ```

## Data Storage

Expense records are stored locally in `expenses.txt`.

The file is automatically created when expenses are saved for the first time.
